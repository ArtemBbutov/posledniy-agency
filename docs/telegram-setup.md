# Заявки в канал или группу Telegram

## Что уже подготовлено

Анкета отправляет имя, контакт и шесть ответов на сервер `/api/brief`, который вызывает Telegram Bot API. Успех показывается только после подтверждения Telegram. При ошибке форма не очищается. Токена бота в странице или GitHub нет.

GitHub Pages раздаёт только статическую страницу. Поэтому его анкета обращается к серверу существующего сайта:
`https://posledniy-agency.butovartemm.chatgpt.site/api/brief`.

## Что сделать владельцу

1. В Telegram откройте [@BotFather](https://t.me/BotFather), отправьте `/newbot`, задайте имя и username бота. Сохраните выданный токен.
2. Создайте канал или выберите существующий. Добавьте бота в администраторы с правом «Публикация сообщений». Для группы достаточно права отправлять сообщения, администратор не обязателен.
3. На этом компьютере откройте файл **Подключить Telegram.command** в папке сайта. Вставьте токен в скрытое поле терминала. Помощник попросит опубликовать `/setup@имя_бота` в канале (или отправить в группу) и выбрать получателя из списка.
4. Напишите в Codex: **«Бот подключён, примени настройки и проверь тестовую заявку»**. Дальше агент перенесёт две настройки в серверные секреты, применит их и отправит тестовую заявку.

Не добавляйте токен в файлы страницы, сообщения группы или GitHub. Помощник сохраняет его только в `.env.local` (права 600, исключён из Git). Если macOS не открывает `.command`, попросите Codex открыть локальный помощник в терминале.

## Что остаётся агенту после этих шагов

- Прочитать локальные `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`, не печатая значения.
- Через Sites `update_environment_variables` записать обе переменные как секреты для проекта `appgprj_6a6f7c1091748191861c7c5dc5ae2edd`.
- Повторно развернуть сохранённую серверную версию: изменение настроек применяется при развёртывании.
- Проверить реальную тестовую заявку с GitHub Pages и получение в выбранном канале или группе.

## Ограничения и ошибки

Без секретов сервер отвечает 503, и анкета прямо сообщает, что приём не подключён. Никакого ложного «отправлено» нет. Доставка без настроенного бота не проверена.

Защита включает ограничение размера, проверку полей, honeypot, запрет посторонних Origin и базовый лимит 5 попыток за 10 минут на IP в пределах экземпляра сервера. Это не распределённая антиспам-система. Автоматических повторов нет; после неопределённого сетевого сбоя ручной повтор может создать дубликат.

Заявки доставляются в Telegram без отдельного архива на сервере. Содержимое и токен не записываются в логи. При перезагрузке страницы неотправленные ответы не сохраняются.
